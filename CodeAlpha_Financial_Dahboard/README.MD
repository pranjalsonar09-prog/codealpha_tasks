#CodeAlpha Financial Sales Performance Dashboard 
Interactive Financial Sales Performance Dashboard created using Microsoft Power BI as part of the CodeAlpha Data Analysis Internship.

##Tools Used
-Microsoft Power BI Desktop

##Dataset
Financial sample Dataset

##Dashboard Features

-Total Sales
-Total Profit
-Gross Sales
-COGS
-Units Sold
-Profit Margin
-Sales by Product
-Year-wise Sales Analysis
-Interactive Slicers

##Project Objective
To analyze financial sales data and create an interactive Power BI dashboard that provides useful insights into sales, profit, products, countries, and overall business performance.
