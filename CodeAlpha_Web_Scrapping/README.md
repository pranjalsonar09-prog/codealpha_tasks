#CodeAlpha_Web_Scrapping
Web Scrapping project completed as part of the CodeAlpha Data Analytics Internship.

##Objective
To collect and extract useful information from web pages using Python web scrapping techniques.

##Tools Used
-Python
-Requests
-Beautifulsoup
-Pandas
-Google colab

##Project work
-Send request to the website
-Extract webpages content
-Parse HTML using Beautifulsoup
-Extract required data
-Store the extracted data
-Perform basic data analysis
